# AI Resume Screening System

An AI-powered recruitment automation project built with n8n, Gemini AI, Google Sheets, Gmail, and Google Calendar.

# Features

- Resume collection using Google Forms
- Automatic resume download
- AI-powered resume analysis using Gemini
- Candidate scoring
- Shortlisted / Rejected / Manual Review classification
- HR email notifications
- Google Calendar interview scheduling
- Daily recruitment summary

#  Tech Stack

- n8n
- Gemini AI
- Google Sheets
