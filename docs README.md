# AI Resume Screening System
# Project Overview
This project automates the recruitment process using AI and n8n. It collects resumes, analyzes them using Gemini AI, notifies HR, and schedules interviews automatically.

# Problem Statement
Recruiters spend significant time manually reviewing resumes. This project reduces manual effort by automating resume screening and candidate management.

# Tech Stack
n8n
Gemini AI
Google Forms
Google Sheets
Google Drive
Gmail
Google Calendar
JavaScript
Features
Resume collection through Google Forms
Automated resume processing
AI-based resume evaluation
HR email notifications
Interview scheduling with Google Calendar
Candidate status tracking
# Project Status
Currently under development. More features such as AI Resume Analysis Dashboard and Duplicate Candidate Detection will be added.
